Behind this prototype: the quiz panel is a single DOM node moved between the popup overlay and the split slot with appendChild — it's never destroyed or rebuilt, so the selected option, the lock state and the timer survive every open/close/split toggle. Closing from split mode used to only strip a CSS class and leave the node sitting in a display:contents slot (which always renders its child) — fixed by always re-parenting the node back into the popup slot on close. Card status (Active / Answered / Missed) reads from the same state.locked the quiz panel already tracks — locking in an answer updates the Cricket Trivia card immediately, no separate source of truth. The bottom "throwback" uses an edge-triggered scroll check (fires once per arrival at the bottom, not once per scroll event while sitting there) with a capped counter, so it can't loop.
