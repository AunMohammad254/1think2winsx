## 2024-05-14 - React.memo on QuizCard
**Learning:** Applied `React.memo` to `QuizCard` in `src/components/quiz/QuizCard.tsx` and moved `status === 'upcoming'` checking logic down into `QuizCard`. This allowed the parent callback (`handleQuizClick`) to completely ignore the `quizzes` state from its dependencies, meaning it stays stable across poll loops and prevents the entire quiz list from constantly re-rendering.
**Action:** Move data-dependent event handling logic down into memoized list item components if doing so allows the parent callback to drop state dependencies, thus preserving memoization across list updates.
